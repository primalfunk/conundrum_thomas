# CT-V2-10 Investigation Targets

## Target catalog

| Kind | Structural basis |
|---|---|
| `OPEN_STORY` | explicit open-story posture; no hidden target |
| `TEMPORAL_GAP` | sparse interval between represented temporal evidence |
| `PERIOD_DETAIL` | represented period with partial detail |
| `EVENT_DETAIL` | represented event with an eligible structural detail gap |
| `EVENT_TIME_UNRESOLVED` | known event with unknown/unresolved time |
| `ROLE_GAP` | represented role with structurally incomplete context |
| `PLACE_GAP` | governed place-history coverage gap |
| `RELATIONSHIP_CONTEXT` | governed incomplete relationship context |
| `ENTITY_IDENTITY_UNRESOLVED` | unresolved/candidate references |
| `CONTRADICTION_CLARIFICATION` | comparable admitted claims with a durable unresolved contradiction |
| `CORRECTION_TARGET_UNRESOLVED` | explicit correction language without deterministic target |
| `USER_NAMED_TOPIC` | current explicit user direction |
| `EXISTING_OPEN_EVIDENTIARY_QUESTION` | CT-V2-08 structural open question |

Every targeted candidate has at least one grounding ID and a nonblank reason code. It can remain unanswerable, private, declined, deferred, recently asked, covered, or unresolved.

## Non-targets

Emotional intensity, guessed trauma, a diagnosis, pathology likelihood, therapeutic leverage, interestingness, name similarity, and model intuition never create or rank a target. Missing fields alone do not require a question. A forgotten date or unresolved ambiguity may remain open indefinitely.

## User direction

A current `USER_NAMED_TOPIC` outranks engine-generated gaps when eligible. Broad direction remains broad. It does not license a fabricated date, event, relationship, emotion, motive, or psychological premise.

## Identity and contradiction

An identity target authorizes asking same/different/unsure; it cannot merge. A contradiction target preserves both claims and never presumes that the newer claim wins, the older claim is false, or the user deceived Thomas. A correction can change current eligibility only through the existing governed correction operation.
