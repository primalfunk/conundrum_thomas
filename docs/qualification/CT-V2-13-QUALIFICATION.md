## Architecture and authority

```text
:thomas:language-renderer
    -> :thomas:domain
    -> :thomas:journal
    -> :thomas:biographer
    -> :thomas:therapy-longitudinal
    -> :thomas:longitudinal

:qualification -> :thomas:language-renderer
```

The renderer accepts only `GovernedRenderCommand`. Its semantic units separate governed meaning from current/historical user content data. `RendererInput` exposes only authorized units and surfaced memories. The narrow `LanguageRealizer` port returns a candidate outcome; it has no store, retrieval, admission, safety, route, target, Journal capture, Android, tool, or network port.

`DeterministicReferenceRealizer` supplies controlled, source-grounded forms. `DeterministicRenderValidator` validates every external, reference, and fallback candidate. `GovernedRenderResult` records the accepted/no-output disposition, measured limits, validation/rejection trace, memory IDs, next fingerprint-only history, and canonical digest.

## Mode rendering

- Journal `NO_RESPONSE`: successful silence, zero realizer calls, no candidate, placeholder, or assistant artifact.
- Journal `REFLECT`: brief current-entry reflection, zero questions, preserved user attribution, no historical or therapeutic authority.
- Journal `ASK_ONE_QUESTION`: current-entry-grounded, non-leading, maximum one question; unsafe realization falls back.
- Biographer: receives the already-selected CT-V2-10 target, renders one neutral question, and cannot choose/replace a target, resolve identity/contradiction, or introduce psychological premises.
- Therapy: receives only CT-V2-12 render-visible support, not the packet or rejected memories; CT-V2-04 permit, CT-V2-05 route, and CT-V2-12 memory disposition remain unchanged.
- Safety: only already-governed direct wording is renderable; exact required text outranks style and is exempt from language repetition rejection.

## Budgets and anti-repetition

Budgets are fixed at 320 characters/2 sentences for brief responses and one-question responses, 640/4 for Therapy, 900/6 for explanation, and 480/3 for safety. Question maxima are 0, 1, or an inherited explanation ceiling of 2. External attempts are capped at two.

Render history retains six normalized-response fingerprints and four opening fingerprints, not response bodies. Exact normalized duplicates are rejected. An opening is rejected when it already occurs twice in the four-entry opening window. Deterministic variants preserve the same act; CT-V2-05 remains the owner of semantic progression.

The large fixed reference sequence qualified 180 commands with 180 accepted responses, zero fallback responses, 180 unique normalized outputs, zero question violations, zero semantic-contract violations, average 37.4 characters, and maximum 38 characters. The surrounding 131-case corpus spans all three conversational modes, safety rendering, seven core semantic-act families, epistemic and temporal forms, and memory/no-memory boundaries. A separate duplicate case produced one expected exact-duplicate rejection and a valid alternative fallback.

## Failure behavior

Unavailable adapters, exceptions, synthetic timeout, empty/malformed candidates, overlong or over-sentence candidates, excess questions, known semantic violations, and recent repetition all degraded through the same validator to a pre-authorized deterministic form. The first-invalid/second-valid case accepted attempt two; all-invalid cases stopped after two attempts. A fallback is revalidated and may return typed `RENDERING_UNAVAILABLE` if no authorized form is valid. `NO_RESPONSE` bypasses realization completely.
