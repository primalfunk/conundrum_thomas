# ADR 0014: Source-first language evidence boundary

## Status

Accepted for CT-V2-08 qualification; production authority denied.

## Decision

Committed exact source evidence precedes perception. A new pure Kotlin `:thomas:language-evidence` module may conservatively propose source-grounded evidence and organize admitted evidence into deterministic state. It cannot persist. Only the qualification composition root may pair it with the CT-V2-07 store, and all durable proposals use the existing admission controller.

Raw prose cannot be consumed by engine, safety, runtime, or app. No model participates. Unsupported or ambiguous input may produce no evidence proposal. Current state excludes private, superseded, review-blocked, and non-current-source evidence. Canonical `.git` metadata may not be relocated as a phase-work technique.

## Consequences

The architecture proves language-to-evidence mechanics without granting production longitudinal or therapeutic authority. Coverage is intentionally bounded; model-assisted perception, retrieval, Android storage, real user data, and mode wiring require later authorization.
