# CT-V2-08 — Language-to-Evidence & State Formation

## Disposition and authority

CT-V2-08 is a synthetic, qualification-only proof of a conservative source-first perception path. It adds no production writer, model, retrieval system, mode behavior, therapeutic rule, or Android persistence.

The enforced order is:

```text
already-admitted exact source revision
  -> bounded deterministic perception
  -> typed, source-grounded proposal
  -> deterministic proposal validation
  -> CT-V2-07 admission controller
  -> deterministic evidence state
```

Raw prose is not formulation, therapeutic policy input, or durable derived psychological state. Unsupported language successfully yields no evidence proposal.

## Implementation

`:thomas:language-evidence` is a pure Kotlin module. Its `perception` package owns committed-source, disposition, source-span, proposal, ambiguity, and correction-candidate contracts plus a bounded deterministic grammar. Its `stateformation` package owns persistence-neutral evidence input, current-state organization, neutral recurrence candidates, structural contradictions, evidentiary questions, and canonical digest generation.

The module depends on `:thomas:longitudinal-admission` and its transitive domain types. It does not depend on the store implementation, Android, engine, safety, renderer, speech, JNI, network, or any model. Only `:qualification` composes it with `:thomas:longitudinal-store`.

CT-V2-07 admission was extended narrowly so an already-admitted correction source can later admit its grounded correcting assertion, correction relation, and supersession atomically. Admission independently revalidates source revision, SHA-256, offsets, and exact source fragment. This does not create a second writer.

## Bounded understanding

The v1 grammar recognizes only audited forms needed to prove the architecture: selected explicit events and residence reports; self-reported emotions; explicit self-beliefs; user interpretations of another person; third-party reported speech; explicit negation; exact, calendar-date, year-range, approximate, relative, ongoing, uncertain, and unknown time forms; and explicit year correction with a supplied unambiguous target.

Questions, hypotheticals, counterfactuals, unattributed quotations, modal speculation, ambiguous pronouns, double negation, ambiguous humor, multiple dates, malformed content, and unsupported forms are not promoted by guesswork.

## State formation

The formed snapshot organizes eligible current assertions as explicit claims, self-reports, self-beliefs, user interpretations, and third-party reports. It includes eligible entities/events, admitted contradictions, unresolved identities/corrections, neutral recurrence candidates, deterministic open evidentiary questions, excluded IDs, rule versions, and a canonical logical digest.

Three comparable reports count toward `REPEATED_REPORTED_OCCURRENCE` only when they come from at least three distinct stable source identities. This is a structural observation, not a trait, disorder, motive, cause, or clinically meaningful threshold.

Contradiction detection is deliberately narrow: same concept, different structured value/polarity, and equivalent temporal scope. Both claims survive and the relation remains unresolved. Different years or different relative phases do not become contradictions.
