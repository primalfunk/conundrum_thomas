# CT-V2-13 Linguistic Anti-Repetition

Render history is ephemeral language-operational state. It records only SHA-256 normalized-response fingerprints, three-token opening fingerprints, semantic act, turn index, and the fixed-required-phrase flag. It stores no durable response body and has zero user-evidence authority.

The recent normalized-response window is six accepted responses. A non-fixed candidate that exactly duplicates any normalized response in that window is rejected. The opening window is four responses; a candidate is rejected after the same three-token opening already appears twice in that window. Fixed governed safety text is exempt because safety meaning outranks stylistic variation.

The deterministic reference realizer chooses among pre-authorized surface forms from governed state and opening history, with no randomness. Fallback also tries a history-compatible governed form before the canonical fallback. The renderer never changes the semantic act to obtain surface variety; CT-V2-05 remains the owner of therapeutic progression and semantic anti-repetition.
