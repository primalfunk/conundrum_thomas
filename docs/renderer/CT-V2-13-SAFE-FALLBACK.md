# CT-V2-13 Safe Fallback

Adapter unavailability, exception, synthetic timeout, malformed/empty output, prohibited meaning, excess length/questions/sentences, unauthorized memory, or repetition never changes the upstream Thomas decision.

The renderer requests no more than two external candidates. If no candidate validates, it deterministically tries only pre-authorized reference forms and the command’s canonical fallback. Each fallback candidate is itself validated against the same command and history. If none is valid, the result is typed `RENDERING_UNAVAILABLE`; the system does not emit unchecked text.

Every non-silent semantic act must carry at least one bounded reference form and deterministic fallback. `NO_RESPONSE` instead carries zero text, zero budget, zero attempts, no memory, and `NO_RESPONSE_ONLY` fallback authority. It returns successful silence without invoking any realizer.

Fallback preserves mode, act, attribution, epistemic and temporal markers, question limit, memory permission, and response budget. It adds no Therapy behavior, target, history, fact, or evidence write.
