# CT-V2-12 Memory Influence Matrix

The matrix is enforced by typed inputs and qualification tests. Retrieval happens only after the safety and CT-V2-05 decisions are fixed.

| Concern | Longitudinal context may influence | Longitudinal context may not influence |
|---|---|---|
| Mode | Nothing | Active mode or mode contract |
| Safety | Nothing | Classification, escalation, permit, prohibition, or specialized procedure |
| Therapy policy | Supporting content after selection | Route, goal, action, technique, progression, or handoff |
| Reflection | At most one eligible, directly connected factual continuity reference | A new formulation, diagnosis, motive, trait, or causal claim |
| Question | Grounding for the already-authorized semantic question | A new question type, extra question, Biographer investigation, or technique |
| Correction | Avoidance of obsolete material and accurate current attribution | Rewriting or deleting history |
| Contradiction | Honest qualification or omission | Choosing a winner or hiding eligible counterevidence |
| Identity | Explicitly resolved continuity or visible uncertainty for explicit recall | Convenient entity merging |
| Recurrence | Neutral repeated-reported-occurrence context | Trait, disorder, cause, or `always` claim |
| Explanation | Support, counterevidence, correction chain, lifecycle, uncertainty | Strengthening confidence or defending retired state |
| Rendering | Only explicitly authorized memory support | Full packet/store access or unsurfaced memory |
| Persistence | Current user source and eligible derived user evidence through CT-V2-07 | Retrieved/surfaced items, plans, assistant prose, route, or operational history as evidence |

## Exact allowed influence

- Select zero or one ordinary eligible historical reference.
- Select bounded evidence for explicit recall or explanation.
- Preserve factual and source-provenance continuity within the selected CT-V2-05 act.
- Prevent an authorized response from contradicting a governed correction.
- Preserve tentative, contested, dated, and unresolved status.

## Exact prohibited influence

- Safety or permit change.
- Route, therapeutic act, technique, goal, escalation, or mode change.
- New psychological or diagnostic interpretation.
- New longitudinal write authority.
- Automatic entity resolution, contradiction adjudication, or private-data use.
- Treating historical user instructions as policy.
- Treating a retrieved or surfaced object as stronger, more recurrent, or more important.
