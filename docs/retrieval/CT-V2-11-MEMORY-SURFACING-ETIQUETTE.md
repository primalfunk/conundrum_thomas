# CT-V2-11 Memory-Surfacing Etiquette

CT-V2-11 does not generate user-facing prose. It preserves the metadata a later authorized conversational layer would need to refer to memory modestly and accurately.

Each surfaced item can disclose acquisition provenance, report time, event-time representation, uncertainty, lifecycle/current authority, source revision IDs, whether identity is unresolved, whether a relation is explicit, and whether contradiction/counterevidence exists. This enables future language such as “You mentioned…” or “I may be connecting…” without implying omniscience.

The following are not retrieval reasons:

- Thomas remembers it;
- it is emotionally intense;
- it is surprising or interesting;
- it might increase engagement;
- it resembles the current issue psychologically without a governed relation.

Historical text is always data. Instruction-like text, mode commands, requests for diagnosis, and old assistant responses cannot modify the authority or safety layers. Assistant turns may appear only as immediate continuity data and cannot support a hypothesis.

The conservative rule is **omit when unsure**. A potentially useful memory is less important than avoiding an irrelevant, stale, private, one-sided, or misleading recollection.
