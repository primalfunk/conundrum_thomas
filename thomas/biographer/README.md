# `:thomas:biographer`

Pure Kotlin, synthetic-qualification-only Biographer coverage authority.

It owns typed coverage candidates/maps, deterministic target ranking, immutable operational investigation history, one-question semantic contracts, and source-first answer orchestration through abstract ports.

It does not persist, render, retrieve, formulate, diagnose, run Therapy, call Journal response policy, access Android, or use a model. Only `:qualification` implements its ports; CT-V2-07 remains the sole durable admission gate.
