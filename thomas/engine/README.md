# `:thomas:engine`

Platform-independent formulation, policy, and intervention-selection structures. It accepts structured state and has no Android, persistence, network, speech, JNI, or concrete-model dependency.

CT-V2-03 adds one narrow deterministic bounded-problem ruleset. Its 21 rules are executable only for controlled qualification and all deny production therapeutic authority. It does not parse raw user prose, infer safety, mutate a durable profile, or invoke a renderer or language model.
