# `:thomas:engine`

Platform-independent formulation, policy, and intervention-selection structures. It accepts structured state and has no Android, persistence, network, speech, JNI, or concrete-model dependency.

CT-V2-03 adds one narrow deterministic bounded-problem ruleset. Its 21 rules are executable only for controlled qualification and all deny production therapeutic authority. It does not parse raw user prose, infer safety, mutate a durable profile, or invoke a renderer or language model.

CT-V2-04 requires a matching revision-bound `OrdinaryTherapyPermit` from `:thomas:safety` before that evaluator can run. No state-only evaluator overload remains; a stale or mismatched permit fails closed before ordinary rules execute.

CT-V2-05 adds `ordinary/`, a qualification-only deterministic repertoire with four opened pathways: listen/support, understand/clarify, bounded practical problem solving, and consolidate/close. Route, goal, action, renderer contract, expected outcome, and progression are explicit. Action history is bound to conversation-evidence revision so repeated unchanged state yields one bounded direction choice and then `NO_AUTHORIZED_ACTION`, not paraphrase loops.

Standalone decision support and optional therapeutic families remain unopened. All 39 CT-V2-05 rules deny production authority.
