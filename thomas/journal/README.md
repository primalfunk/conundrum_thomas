# `:thomas:journal`

Pure Kotlin CT-V2-09 Journal capture authority. It defines committed-entry, revision, privacy,
response-posture, and response-rendering contracts. It owns no database and has no production
writer. Qualification supplies a CT-V2-07 admission adapter and CT-V2-08 language processor.

Journal is capture, not Therapy or Biographer investigation. `NO_RESPONSE` is the default.
