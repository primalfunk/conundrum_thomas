# `:thomas:domain`

Platform-independent shared contracts and future canonical state types. This module may not depend on Android, persistence, JNI, speech, a concrete model, engine, safety, or runtime.

CT-V2-02 adds the architectural Therapist, Biographer, and Journal mode contracts. These describe primary function and evidence disposition while granting no runtime, profile-mutation, or language-model decision authority. The narrow renderer request contract remains unchanged.
