# `:thomas:language-renderer`

Pure Kotlin, synthetic-only CT-V2-13 governed language realization. The module adapts sealed Journal, Biographer, Therapy, and safety render contracts into minimal typed commands; treats every external realization as untrusted; validates candidates; and supplies deterministic reference/fallback language.

It has no store, retrieval, evidence admission, model, Android, network, or V1 authority. See `docs/renderer/` and ADR 0019.
